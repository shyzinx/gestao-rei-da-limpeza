🧹 Gestão Rei da Limpeza

Sistema web desenvolvido para facilitar o gerenciamento de serviços de limpeza, centralizando informações de clientes, serviços, agenda, financeiro e relatórios em um único lugar.

O projeto foi desenvolvido com foco em simplicidade, organização e praticidade, permitindo que o usuário acompanhe as principais informações do negócio de forma rápida e intuitiva.

📌 Sobre o projeto

O Gestão Rei da Limpeza é uma aplicação web criada para auxiliar no controle e gerenciamento de uma empresa de serviços de limpeza.

A aplicação permite organizar os dados dos clientes e serviços realizados, além de acompanhar a agenda e informações financeiras do negócio.

O sistema utiliza o Supabase como banco de dados, permitindo que as informações sejam armazenadas de forma persistente e acessadas pela aplicação online.

🗄️ Banco de dados

O projeto utiliza o Supabase para armazenamento dos dados.

Entre as informações armazenadas estão:

Clientes
Serviços

A integração permite que os dados permaneçam armazenados mesmo após o usuário fechar ou atualizar a página.

🎯 Objetivo

O principal objetivo do projeto é digitalizar e simplificar o gerenciamento de uma empresa de serviços de limpeza, reduzindo a necessidade de controles manuais e centralizando as informações importantes em um único sistema.
